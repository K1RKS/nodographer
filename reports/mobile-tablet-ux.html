Context

The map UI in frontend/index.html is desktop-first today:

  • No viewport meta (unlike frontend/node_report/index.html)
  • Five controls stack on one left corner (zoom, search, ruler, list, layers)
  • Custom controls forced to 30×30 in frontend/css/meshmap-default.css
  • Expanded layer panel fixed at 500×140 with overflow: hidden
  • Popups forced to 350px wide / 250px min height
  • Legend defaults open at 200×120 top-right (frontend/js/meshmap-legend.js)
  • No invalidateSize on rotate/resize; #map uses bare 100vh
Approach: balanced MVP — viewport + gesture fixes + touch-sized controls + compact collapsible panels via CSS/@media and small JS. Defer full bottom-sheet redesign and node-report DataTables overhaul.

Implementation flow:

Viewport + 100dvh + safe-area→ Map pinch vs page zoom→ Orientation invalidateSize→ 44px controls + declutter→ Capped layers + collapsed legend→ Responsive popups + search

Phase 1 — Foundation (gestures, rotation, layout)

Files: frontend/index.html, frontend/css/meshmap-default.css

  1. Add viewport meta with safe-area support: width=device-width, initial-scale=1, viewport-fit=cover. Do not lock user-scalable=no (a11y).
  2. Map fills visible viewport: html, body, #map { height: 100%; height: 100dvh; overflow: hidden; } plus overscroll-behavior: none.
  3. Safe-area padding for Leaflet corners (notch / home indicator).
  4. Fix missing vertical-center corner CSS (keep left stack mid/safe with larger targets).
  5. On resize, orientationchange, and visualViewport resize: debounce map.invalidateSize({ animate: false }).
  6. Map vs page pinch: Leaflet container touch-action: none; scrollable chrome uses touch-action: pan-y + overscroll-behavior: contain.
  7. touch-action: manipulation on control buttons to reduce double-tap zoom on chrome.

Phase 2 — Touch targets and control declutter

Files: frontend/css/meshmap-default.css, frontend/index.html

User report: menus too small in some places, too large in others.

  1. Under @media (pointer: coarse), (max-width: 900px): raise custom controls from 30×30 to min 44×44 (ruler, layers toggle, view-as-list, search); match Leaflet touch zoom sizing.
  2. On narrow screens (max-width: 700px): keep zoom, search, layers visible; move ruler and view-as-list into a compact “More” control.
  3. Hide or shrink scale on very small widths; keep attribution readable with max-width wrap.
  4. Spiderfy banner: center with transform: translateX(-50%); shrink font on phones.

Phase 3 — Menus that eat the screen (layers + legend)

Files: frontend/css/meshmap-default.css, frontend/js/meshmap-legend.js, small hook in frontend/index.html

  1. Layer control: replace fixed height: 500px !important; overflow: hidden with expanded max-height: min(50dvh, 360px); max-width: min(90vw, 280px); overflow-y: auto;, larger labels / font-size: 16px, auto-collapse after selection or outside tap on coarse pointers.
  2. Legend: on narrow/coarse, start collapsed (“Show Legend” chip); cap expanded width; larger Hide/Show; keep Dark reachable.

Phase 4 — Search and popups on small screens

Files: frontend/css/meshmap-default.css, frontend/js/meshmap-markerFunctions.js, frontend/index.html

  1. Search: near full-bleed when open; results max-height: ~40vh; input font-size: 16px.
  2. Popups: drop fixed 350px width → max-width: min(350px, calc(100vw - 32px)); reduce tab min-height; allow scroll; fix maxWidth (currently maxwidth); increase auto-pan padding for controls/safe areas.
  3. Optional: stop popup tab hash links from fighting leaflet-hash.

Phase 5 — Verification

Manual checks on phone + tablet (portrait and landscape):

  • Pinch-zooms the map, not the whole page
  • Rotate keeps map sized correctly (no grey gaps / clipped controls)
  • Layer menu scrolls and does not cover most of the screen
  • Controls are easy to hit; collapsed chrome leaves most of the map visible
  • Node popup fits and can be closed; search usable with on-screen keyboard
  • Desktop layout remains essentially unchanged (media queries / coarse-pointer gated)

Explicitly out of scope for this pass

  • Full mobile bottom-sheet / Material-style redesign
  • Reworking frontend/node_report/index.html DataTables (responsive: false, wide columns) — follow-up
  • Enabling unused elevation plugin or geolocation

Implementation notes

  • Prefer a small helper (e.g. frontend/js/meshmap-mobile.js) for invalidateSize, layer auto-collapse, and mobile-default legend collapse; CSS in meshmap-default.css.
